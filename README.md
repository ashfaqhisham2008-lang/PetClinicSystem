# Pet Clinic Management System

A Veterinary Management System developed using Java Swing, JDBC, MySQL and Jasper Reports.

## Features

- Login System
- Dashboard
- Customer Management
- Pet Management
- Appointment Management
- Payment Management
- Report Center
- Jasper Reports

## Reports

- Customer Report
- Pet Report
- Appointment Report
- Payment Report

## Technologies Used

- Java
- Java Swing
- JDBC
- MySQL
- Jasper Reports
- GitHub

## Design Patterns

- MVC Architecture
- Singleton Pattern

## Custom Exceptions

- InvalidAgeException
- InvalidAmountException
